Acerca del informe

Fórmula de clasificación

Cada fila se clasifica automáticamente al cargar el archivo, replicando la fórmula original de Excel a partir del estado de la admisión (e_admi), el número de factura (n_fact), el valor admisionado (v_admi), la cuenta de cobro (n_cxc) y el resultado de radicación (Fecha radicacion). El resultado nunca se toma de la columna cacheada del Excel: se recalcula siempre.

Todo se ancla a número de admisión + fecha + cliente

El sistema de origen a veces exporta la misma línea de servicio dos veces: una vez antes de facturarse y otra vez ya facturada (mismo n_admi, misma f_admi, mismo cliente y mismo valor, pero con distinto número de factura). Si se sumaran ambas copias, esa admisión quedaría contada dos veces. Esto es distinto de una admisión dividida entre dos clientes (por ejemplo un SOAT repartido entre dos aseguradoras) — eso es normal y ambos clientes se conservan. Por eso, al cargar cada archivo, la app agrupa por n_admi + f_admi + n_clie + v_admi (los cuatro a la vez) y solo colapsa cuando coinciden exactamente — así el valor admisionado nunca se duplica, pero tampoco se pierde ningún cliente legítimo. Cuando esto ocurre, el mensaje de carga te avisa cuántas líneas se colapsaron.

Categoría de cliente

ARL, SOAT, Medicina Prepagada, Pólizas de Salud y Particulares se infieren del texto de la entidad (n_clie). Las entidades que no encajan en ninguna de esas categorías (convenios empresariales, colegios, iglesias, etc.) se agrupan como "Convenios / Empresas".

Acceso y usuarios

Si el administrador conectó Supabase, el acceso al informe requiere iniciar sesión, y solo los usuarios con rol "admin" pueden cargar o eliminar datos de sedes — los de rol "consulta" solo pueden ver los informes. Esta restricción se aplica también a nivel de base de datos (no solo en la pantalla), así que no se puede saltar editando el navegador.

Almacenamiento

Si no hay Supabase conectado, la información se guarda localmente en el navegador (IndexedDB) sin necesidad de iniciar sesión. Si Supabase está conectado, los datos son compartidos entre todos los usuarios autorizados, desde cualquier computador.
